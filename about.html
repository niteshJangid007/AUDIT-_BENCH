What Audit Bench is — and isn't.

Audit Bench is a client-side static code scanner. It reads a snippet of your app — a backend route, a frontend handler, a query, a config file — and flags patterns that map to the OWASP Top 10, line by line, with a suggested rewrite for each finding.

It works entirely in your browser. Nothing you paste, upload, or scan is ever sent to a server — there's no backend involved in the scanning itself, only in the login system that gates access to the tool.

What it isn't: this is a heuristic pattern scan, not a full security audit, SAST/DAST pipeline, or penetration test. A clean scan doesn't mean your code is safe — it means it didn't match the specific patterns this tool checks for. Treat findings as a starting point for review, not a certificate.

Coverage: Injection (SQL injection, XSS, command injection), broken access control, cryptographic failures, security misconfiguration, authentication failures, software & data integrity failures, logging & monitoring failures, and server-side request forgery — 10 categories aligned to the OWASP Top 10 (2021).
